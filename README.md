## Overview

This repository holds the source for my personal portfolio: a fast, dependency-light site built with pure HTML, CSS, and JavaScript. It's designed to introduce me as a Full-Stack and Game Developer, with an interactive 3D hero, a categorized project showcase, and a fully responsive layout — no framework, no build step, just clean front-end fundamentals doing the heavy lifting.

**Live site:** [portfolio-website-ivory-ten.vercel.app](https://portfolio-website-ivory-ten.vercel.app)

## Local Setup

Clone the repository and open it directly — no build tools or dependencies required.

```bash
# 1. Clone the repository
git clone https://github.com/AbelXeon/Abel_Tiruneh-portfolio.git

# 2. Move into the project directory
cd Abel_Tiruneh-portfolio

# 3. Open index.html in your browser
```

For live-reload during edits, serve the folder with any static server — for example, the Live Server extension in VS Code.
